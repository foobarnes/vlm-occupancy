# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature instead of opening
a public issue. Include the affected version, expected impact, and minimal
reproduction steps.

Do not include API keys, Home Assistant credentials, camera snapshots, camera
URLs, entity identifiers, public IP addresses, or unredacted diagnostics in any
report. Revoke and replace a credential immediately if it is exposed.

Routine bugs that do not involve security or privacy can be filed as public
issues.
